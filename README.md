# MS_Power_Automate-Agente_Conferencia_Doc_Embarque
Este conjunto de automações (Power Automate / Azure Logic Apps + UiFlow) gerencia o recebimento, organização e conferência de documentos de embarque da DHL (Aéreo). O processo cobre desde o alerta formal da DHL até a inserção dos dados validados em um Sistema de gerenciamento processos de Importação.
